安全边界

newLlmRequestSent=false 页面复放已有真实产物，不再次调用模型。
secretsRead=false 不读取、不展示 API Key 或 Token。
contestantCodeExecuted=false 只读 evidence 检查不执行选手代码。
commandExecuted=false 不运行命令、不运行 pytest、不执行 Notebook。
controlledDockerEvidenceExecuted=true 受控 Docker evidence 来自预先执行的 CLI 报告，页面不触发容器执行。
readonlyOnly=true · sourceGradingModified=false reportDetail 只展示 evidence，不替代真实 Grading DSL。
realPublish=false 所有 DSL 仍需人工审核，审核前不得发布。
