# Python 数据清洗入门实验

## 背景

课程希望学生掌握使用 Python 和 Pandas 处理小型 CSV 数据集的基本流程。实验素材是一份包含缺失值、重复行和异常分数的学生成绩表。

## 学习目标

- 能读取 CSV 文件并查看数据概况。
- 能识别缺失值、重复记录和异常值。
- 能完成基础清洗并输出清洗后的结果文件。
- 能用简单统计指标说明清洗前后的变化。

## 建议实验步骤

1. 准备 `students.csv`，字段包括 `student_id`、`name`、`score`、`class_name`。
2. 使用 Pandas 读取 CSV，并输出前 5 行和字段类型。
3. 统计缺失值数量，删除重复的 `student_id`。
4. 将不在 0 到 100 范围内的 `score` 标记为异常并修正或剔除。
5. 输出 `cleaned_students.csv` 和 `summary.json`。

## 可考核点

- 是否生成清洗后的 CSV 文件。
- 是否在 `summary.json` 中记录原始行数、清洗后行数和异常值数量。
- 是否能解释每一步清洗策略。
