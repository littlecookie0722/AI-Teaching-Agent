# Linux 日志分析与故障定位实验

## 背景

运维课程需要一个面向初学者的日志分析实验。学生需要读取一份模拟的 Web 服务访问日志，定位高频错误、异常 IP 和慢请求。

## 学习目标

- 理解访问日志的基本字段。
- 能用命令行或 Python 脚本统计状态码分布。
- 能筛选 5xx 错误和慢请求。
- 能生成简短故障分析报告。

## 建议实验步骤

1. 阅读 `access.log`，理解时间、IP、路径、状态码和响应耗时字段。
2. 统计 200、404、500 等状态码出现次数。
3. 找出 5xx 错误最多的前 3 个接口路径。
4. 找出响应耗时超过 1000ms 的请求并保存到 `slow_requests.txt`。
5. 编写 `report.md`，说明可能的故障原因和后续排查建议。

## 可考核点

- 是否输出状态码统计结果。
- 是否正确筛选慢请求。
- 是否在报告中给出清晰的排查结论。
