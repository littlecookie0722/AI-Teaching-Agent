# Web API 自动化测试入门实验

## 背景

软件测试课程需要一个 API 测试实验。学生需要围绕一个本地 Todo API 编写测试用例，覆盖创建任务、查询列表、更新状态和参数错误。

## 学习目标

- 理解 REST API 的请求方法和状态码。
- 能设计正常路径和异常路径测试。
- 能使用 pytest 编写接口自动化测试。
- 能输出测试报告并解释失败原因。

## 建议实验步骤

1. 阅读 Todo API 说明，接口包括 `POST /todos`、`GET /todos`、`PATCH /todos/{id}`。
2. 编写创建任务的正常路径测试，检查返回状态码和响应字段。
3. 编写查询任务列表测试，确认刚创建的任务可被读取。
4. 编写更新任务状态测试，确认 `completed=true` 生效。
5. 编写参数错误测试，例如缺少 title 时返回 400。
6. 运行 pytest 并生成 `api_test_report.json`。

## 可考核点

- 测试用例是否覆盖核心接口。
- 是否包含参数错误测试。
- pytest 是否全部通过。
- 报告是否包含通过数、失败数和失败详情。
